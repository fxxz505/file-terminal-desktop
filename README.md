# 资料终端桌面版

资料终端是一个 Windows 本地优先的资料管理与 AI 助手。你可以把已有文件夹或文件接入软件，原文件仍留在原位置；软件只在本机保存索引、备注、标签和对话，帮助你快速找到资料并在需要时调用 AI。

当前版本：`v0.1.18`

## 下载与安装

**[下载最新 Windows 版本](https://github.com/fxxz505/file-terminal-desktop/releases/latest)**

安装版和便携版都在 GitHub Release 页面的 `Assets` 中：

1. 安装版：下载名称以 `_x64-setup.exe` 结尾的文件，双击安装。
2. 便携版：下载 `资料终端便携版-win-x64.zip`，解压后双击其中的 exe。
3. 适用于 64 位 Windows 10/11，不需要账号。

便携版会在 exe 同级创建 `资料终端数据` 文件夹。数据库、密钥、索引、模型、对话和设置都保存在这里。安装版重装或应用内更新时会保留该资料库；若安装过程被意外中断，应用会自动尝试恢复临时保护的资料目录。请不要删除同级数据文件夹。

## 三分钟开始使用

1. 在首页把整个文件夹拖入窗口，或点击“接入文件夹”。也可以在“上传文件”区域拖入或选择多个文件。
2. 接入文件夹只保存原路径和索引，不会复制、移动、删除或改写原文件；上传文件会复制到应用数据目录的 `uploaded-files`。
3. 右键文件夹或文件，添加备注、标签，设置云端访问权限。已有备注和标签会保留，由你决定是否修改。
4. 打开“本地搜索”，按名称、路径、备注、标签和已提取文本查找资料。
5. 单击文件夹可在软件内逐层浏览；单击文件可预览支持的格式，或选择“在资源管理器中打开”。

例如，为游戏资料添加 `游戏` 标签或备注后，搜索“游戏”即可找到相关文件夹和文件。

## 主要功能

- 文件夹和文件拖拽接入，保留原始位置。
- 备注、标签和固定的云端上传权限标签。
- 本地全文搜索、路径搜索、标签搜索和备注搜索。
- 图片、文本、PDF 预览；Office 文档提供基础提取和可选的 PDF 转换预览。
- 图片和 PDF 首页缩略图缓存，可在图库中浏览。
- 文件变化后自动进入索引队列；支持暂停、恢复和逐文件增量更新。
- 新增“索引诊断”：按状态查看正文提取、OCR/转写、向量和缩略图处理情况；失败项可在不修改原文件的前提下重试，并可导出不含正文的诊断摘要。
- 新增“后台任务”：统一显示真实的索引与媒体任务状态、进度、错误摘要和可用操作。
- 本地模型优先回答问题，也支持兼容 OpenAI API 的自定义云端服务商。
- 本地 AI 与云端 AI 对话自动保存，可查看、删除和解析步骤、建议与代码块。
- Agent 只在受控工作区写入文件；修改已有文件需要明确批准，并会先创建备份。
- 本地数据库使用 SQLCipher 加密，支持 Windows 凭据、DPAPI 密钥副本、加密备份和自动恢复。
- 关于页面支持检查更新、下载进度、自动安装和重启。

## 当前完成度与下一步

日常资料管理、本地搜索、受控 AI 协作与数据保护已经可用。以下内容仍属于后续增强或需要在最终用户设备上验证的范围：

- OCR 语言包、embedding 与 Whisper 模型的内置下载、校验与更新；目前 embedding 与 Whisper 模型通过原生文件选择器登记，OCR 语言包由 Tesseract 自行管理。
- 面向网络盘、超大资料夹、权限频繁变化、中文路径和不同 GPU 的长期稳定性与性能验证。
- 更高保真的 Office 渲染，以及发送云端前更细粒度的资料审阅与脱敏规则。
- Agent 对更多语言和构建工具的受控支持；当前只允许固定的 `npm` 与 `cargo` 检查命令。

## AI 助手

### 本地 AI

在“资料空间”下载本地运行时和模型，或选择电脑中已有的 GGUF 模型。模型可选择自动、CPU 或 GPU 模式，并设置线程数和上下文长度。

没有安装模型时，文件管理和关键词搜索仍然可以使用。

### 云端 AI

在“AI 助手”或设置页面中添加兼容 OpenAI API 的服务商：填写基础地址、API Key，点击“获取模型”，再选择要使用的模型。API Key 只保存在 Windows Credential Manager，不写入 SQLite 数据库。

复杂任务可以由本地 Agent 整理资料后交给云端 AI。发送前会遵守每个文件的云端权限，选择允许外发的最小资料，并对敏感内容进行脱敏或摘要化。云端返回的代码和建议会先回到本地端检查，不能直接当作系统命令执行。

## 云端访问标签

每个文件夹和文件都显示云端标签：

| 标签 | 含义 |
| --- | --- |
| 云端：禁止上传 | 默认值，只用于本地索引和本地 AI。 |
| 云端：允许上传 | 任务需要时可以纳入最小化的云端请求。 |
| 云端：每次询问 | 每次准备外发时都需要你确认。 |

标签不能替代安全审查。即使选择允许上传，软件仍会进行最小化选择、敏感规则脱敏和提示词注入检查；接入机密资料前，请确认云端服务商的条款和权限。

## 数据位置与隐私

- 默认数据目录是 exe 同级的 `资料终端数据`，不是 C 盘用户目录。
- 如需移动数据，请先关闭应用，再把 exe 和同级数据文件夹一起移动。
- 接入文件夹只保存引用和索引；移除引用不会删除原文件。
- 数据库使用 SQLCipher 全库加密。密钥保存在当前 Windows 用户的 Credential Manager，并有同一用户可解锁的 DPAPI 副本。
- 应用支持 AES-256-GCM 加密备份。恢复前会校验备份，原数据库和恢复文件会保留。
- 建议开启 BitLocker 或 Windows 设备加密，并不要删除 Windows 凭据和应用数据目录。

如果数据库暂时无法解锁，软件会进入安全恢复模式，保留原数据库、WAL、SHM 和恢复目录，并自动尝试恢复。只有在你点击“保留旧数据并新建资料库”后，才会在 exe 同级创建新的空资料库。

## 搜索、预览与索引

- 支持按文件名、路径、备注、标签和已提取正文搜索。
- `txt`、`md`、`json`、`csv`、PDF、`docx`、`pptx`、`xlsx` 可建立本地索引。
- 文本、PDF 和 Office 使用独立限制：文本最多 512 KB；PDF 最多 32 MB、200 页、100,000 字；Office 最多 64 MB，且限制压缩包条目、单条与总解压量，避免 ZIP Bomb。超限、损坏、加密或不支持的文件会显示“只索引元数据”或安全原因，不会静默当成空正文。
- 安装 LibreOffice 后，可将接入的 Office 文件转换为 PDF 进行隔离预览；复杂公式、宏和嵌入对象可能与原应用不同。
- 已配置本地 embedding 模型时，搜索可使用向量语义检索；没有 embedding 模型时会明确回退到关键词搜索。
- 图片缩略图无需额外组件；PDF 缩略图需要本机存在 `pdftoppm`。

## OCR、音视频与本地工具

“本地搜索”中的工具管理会清楚区分应用下载、固定 winget 包和用户选择的外部模型。Windows `winget` 安装固定官方包前必须确认：

- Tesseract OCR：图片文字识别，需要对应语言包。
- FFmpeg：音视频转码。
- LibreOffice：复杂 Office 转 PDF 预览。

音视频转写还需要 Whisper CLI 和本地 Whisper 模型。OCR 和转写结果只写入本机索引，未安装依赖时软件会显示明确错误，不会静默上传文件。

取消排队媒体任务不会启动进程；取消运行中的 OCR、FFmpeg 或 Whisper 任务会终止当前进程树、清理临时目录，并且不会写入识别结果或全文索引。应用意外关闭后的运行任务会安全回到队列等待重新处理。

## Agent 安全边界

- 默认只允许在受控工作区中新建文件。
- 不允许删除文件、越界写入、执行任意命令、联网代码或自动发布。
- 自动构建和测试只允许固定的 `npm`/`cargo` 检查命令。
- 如果要修改已有普通文件，必须点击“批准后修改已有文件”并再次确认。
- 修改前会创建本机备份；失败后最多执行两次有限的诊断和最小修复循环。
- 最终报告会记录步骤、构建/测试结果和受限资料数量，不保存受限原文。

## 已知限制

- 本地模型、embedding 模型、Whisper 模型和部分工具需要首次下载或自行准备；OCR 还需要相应语言包。
- 云端标签和脱敏可以降低外发风险，但不能保证云端服务商绝对不会保存或处理已发送内容。发送机密资料前，请先审阅将要发送的内容与服务商条款。
- 复杂 Office 排版、公式、宏和嵌入对象不保证完全还原；PDF 缩略图还需要本机存在 `pdftoppm`。
- 网络盘、权限频繁变化、超大目录、GPU 推理和特殊中文路径仍需要在实际设备上验收。OCR、Whisper、LibreOffice 和 GPU 推理是否可用取决于本机依赖、驱动和模型。

## 软件内更新

进入侧边栏的“关于”：

1. 点击“检查更新”。软件会显示连接 GitHub 的动效，网络失败时自动重试，并提供“重试检查”。
2. 发现新版本后点击“立即更新”。软件会验证签名，显示下载进度，完成后自动安装并重启。
3. 更新只替换程序文件，不会删除 exe 同级的 `资料终端数据`。

## 从源码运行

仅供开发者使用：

```powershell
npm install
npm run desktop:dev
```

验证前端：

```powershell
npm test
npm run build
```

完整验证（需要 Rust 工具链）：

```powershell
npx tsc --noEmit
cargo fmt --manifest-path src-tauri/Cargo.toml -- --check
cargo test --manifest-path src-tauri/Cargo.toml
```

仓库中的 `manual-test-kit/` 是可反复使用的虚构资料夹。关键的接入、正文索引、搜索和移除引用不删除源文件流程已经由 Rust 临时目录自动化测试覆盖；其余云端协作与真实 Windows/Tauri 界面操作仍保留人工验收用途。
