# 资料终端桌面版

资料终端是一个 Windows 本地优先的资料管理与 AI 助手。你把已有文件夹接入软件后，原文件仍保留在原位置；软件只在本机建立索引、保存备注和标签，帮助你更快找到资料并在需要时调用 AI。

## 下载与安装

**[下载最新 Windows 安装包](https://github.com/fxxz505/file-terminal-desktop/releases/latest)**

1. 打开下载页，在 `Assets` 中下载名称以 `_x64-setup.exe` 结尾的安装程序。
2. 双击安装包，按提示完成安装。
3. 从 Windows 开始菜单打开“资料终端”。

适用于 64 位 Windows 10/11。首次启动不需要账号，也不会要求上传资料。之后有新版本时，应用会在启动后检查 GitHub Release，并在你确认后下载、安装和重启。

## v0.1.14 应用内更新

- 侧边栏新增“关于”。软件版本、更新状态和更新操作统一放在这里，避免在设置页分散查找。
- 点击“检查更新”；发现新版本后会显示“立即更新”。点击后自动验证签名、下载、安装并重新启动，无需手动前往 GitHub 下载。
- 下载期间会显示进度。更新只替换程序文件，`exe` 同级资料库、密钥、索引、模型和设置不会被清空。

## v0.1.13 资料库位置与安全恢复

- 默认数据目录固定在 `资料终端.exe` 同级的 `资料终端数据`。请将便携版解压到希望保存数据的位置；首次启动会在同级创建该文件夹，资料库、DPAPI 密钥副本、模型、索引、对话、缓存和设置都保存在其中，而不是新建到 C 盘。
- 下载页还提供 `资料终端便携版-win-x64.zip`。解压后直接双击其中的 `资料终端.exe`；更新时只替换 exe 文件，不要删除同级的 `资料终端数据`，已有资料会继续使用。
- 旧版本存于 `%LOCALAPPDATA%\资料终端` 或旧位置指针的数据，只会在首次可写启动时**复制**到 exe 同级目录；源目录始终保留，应用不会再把新数据写回 C 盘。
- 如需更换保存位置，请先关闭应用，再将 `资料终端.exe` 和同级的资料目录一起移动到目标文件夹；应用不提供写入任意目录的运行资料库。
- 如果数据库无法解锁，恢复页提供“保留旧数据并新建资料库”：它会在 exe 同级创建 `资料终端数据-新建`（必要时自动编号），保存新的位置指针并重启。旧数据库、WAL、SHM 和恢复目录不会被删除、移动或覆盖。
- exe 所在目录不可写时，应用会要求将便携版解压到可写的文件夹；为避免新数据落到 C 盘，不会静默回退到 Windows 本地数据目录。

## v0.1.11 数据保护更新

- 首次创建加密资料库时，应用会同时将数据库密钥保存到 Windows Credential Manager，并在应用数据目录中的 `database-key.dpapi` 创建仅当前 Windows 用户可解锁的 DPAPI 加密副本。
- 更新后若 Credential Manager 条目暂时缺失，应用会自动使用 DPAPI 副本恢复同一把密钥并写回凭据库，资料夹引用、索引、备注、标签、对话、模型设置和任务记录会继续使用原数据库。
- 已存在数据库但两种密钥来源都不可用时，应用会停止打开并保留原文件；不会再移动旧数据库、更不会创建空数据库覆盖你的资料。请保留应用数据目录，并使用原 Windows 用户账户或此前创建的 `.ftbackup` 加密备份恢复。

## v0.1.10 更新内容

- 启动时会自动扫描当前应用数据目录中的 `database-recovery\unreadable-*`。若旧数据库能由当前 Windows Credential Manager 密钥解锁，应用会把可恢复的资料夹引用、索引、对话、模型设置和任务记录安全合并到当前数据库；同 ID 的当前记录不会被覆盖。
- 每个恢复目录会写入 `AUTO_RESTORE_STATUS.txt` 记录结果，但原始数据库及其 WAL/SHM 文件始终保留。若当前凭据无法解锁旧库，应用会在之后的每次启动继续自动尝试；密钥已永久丢失时，SQLCipher 密文无法被应用或 AI 解密。

## v0.1.10 界面更新

- 右键修改“云端访问权限”会立即在当前页面更新，后台异步保存；保存失败才回退并显示错误，不再等待全量状态刷新。
- 首页提供“上传文件”快捷入口：支持拖入该区域或选择多个文件。文件会复制到应用数据目录中的 `uploaded-files` 并建立索引，原文件不会移动或删除；文件夹仍使用“接入文件夹”原位引用。
- 侧边栏新增“设置”，可在本机调整界面文字大小、手动检查更新和安装可用更新。

## v0.1.9 更新内容

- 修复旧版 SQLCipher 本机凭据无法解锁资料库时，应用会在窗口创建前直接退出的问题。现在应用会把无法解锁的数据库及其 WAL/SHM 恢复文件完整保留在当前应用数据目录的 `database-recovery\unreadable-<编号>`，并以安全恢复模式打开。
- 启动后首页会显示“数据库恢复提示”，说明旧资料的恢复目录。恢复目录不会被应用自动删除；请保留它，并在需要找回旧资料时使用原 Windows 用户凭据或联系支持。

## v0.1.8 更新内容

- 首页现在支持把一个完整文件夹直接拖入窗口原位接入；仍可使用“接入文件夹”按钮。应用只保存引用、索引、备注和标签，不会导入、移动或重建原文件夹。
- 已配置 embedding 模型时，资料夹索引完成会自动、合并地更新向量索引，只重算有变动的文件；没有 embedding 模型时仍使用本地关键词搜索。
- “本地搜索”增加本机工具管理，可通过 Windows `winget` 一键安装固定官方包：Tesseract OCR、FFmpeg、LibreOffice；不会执行用户提供的命令或安装任意包。
- 侧边栏新增独立“AI 对话”页面，在本机查看与删除已保存的本地/云端问答和结构化步骤；“AI 助手”专注于新任务和配置，避免重复内容。
- Agent 默认仍只新建文件。只有你点击“批准后修改已有文件”并再次确认时，才可改动当前 AI 工作区内建议明确列出的普通文件；每个文件最大 2 MB，修改前会备份到应用数据目录，且不允许删除、越界路径、命令执行或联网代码。
- 表单错误会显示在对应配置项上方；搜索、OCR、治理和工具管理区已针对窄窗口优化按钮间距、换行和文字显示。

这些能力都保持本地优先：缓存、索引、备份和识别文本仅写入应用数据目录，原始资料不会被复制或改写。

## 三分钟开始使用

1. 在首页将一个资料文件夹拖入窗口，或点击“接入文件夹”选择它。
2. 软件递归建立本地索引，但不会复制、移动、删除或改写其中的文件。
3. 给资料夹或文件添加备注、标签；右键编辑时会保留原有内容，由你决定是否修改。
4. 在“本地搜索”输入关键词，按名称、路径、备注、标签和已提取文本查找资料。
5. 单击文件夹可在应用内逐层浏览；单击文件可预览支持的格式，或用“在资源管理器中打开”回到原位置。

例如，为游戏资料添加 `游戏` 标签或备注后，搜索“游戏”即可找到相应文件夹和文件。

## AI 助手如何工作

- 可在应用内下载小型本地模型和运行时。模型下载完成后，本地 AI 会把自然语言问题转换为检索词，并结合本机索引返回相关资料。
- 模型尚未下载时，基础关键词检索仍可使用。
- 可在设置中添加兼容 OpenAI API 的云端服务地址、API Key，并点击“获取模型”选择服务商提供的模型。API Key 仅存储在 Windows Credential Manager，不写入 SQLite 数据库。
- 本地与云端对话会保存在本机；应用可解析云端返回的步骤、代码和建议，但不会把它们直接当作命令执行。
- 复杂任务可由本地 Agent 组织云端请求：只选取允许外发的资料、对敏感内容脱敏，并将本地禁止上传的资料改为必要的抽象说明。默认写入只会在你选定的目录或应用受控工作区中新建文件。若你明确选择“批准后修改已有文件”，应用会要求二次确认、仅限当前工作区内建议明确列出的普通文件，并在修改前创建本机备份；仍拒绝删除、越界路径、联网代码和命令执行。

## 云端上传标签

每个资料夹和文件都显示固定的云端标签；本地模型会优先识别它：

| 标签 | 含义 |
| --- | --- |
| 云端：禁止上传 | 默认值。内容只用于本地索引和本地 AI。 |
| 云端：允许上传 | 在任务确有需要时，内容可以被纳入最小化的云端请求。 |
| 云端：每次询问 | 每次准备外发时由你确认。 |

即使标记为允许上传，应用仍会进行最小化选择、敏感规则脱敏和提示词注入检查。请在接入资料前自行确认其访问权限与云端服务商条款。

## 隐私与数据位置

- 索引、备注、标签、对话记录和已下载模型位于当前“应用数据目录”。默认是 `资料终端.exe` 同级的 `资料终端数据`；若需换位置，请移动 exe 与同级资料目录。
- 应用更新只替换程序本体，绝不主动删除应用数据目录。旧版本数据迁入时只复制，旧目录仍由你保留和管理。
- 接入资料夹只建立引用和索引，不会改变原始资料；移除资料夹也只删除软件内数据。
- 默认云端策略为“禁止上传”。
- SQLite 数据库使用 SQLCipher 全库加密。数据库密钥保存在当前 Windows 用户的 Credential Manager，并有同一 Windows 用户可解锁的 DPAPI 加密副本；首次启动会先安全迁移旧明文数据库，迁移失败时保留原库。请同时开启 BitLocker/设备加密，并避免删除 Windows 凭据或应用数据目录。

## 支持的搜索与预览

- 支持按文件名、路径、备注、标签和已提取正文搜索，可筛选资料夹与文件类型。
- `txt`、`md`、`json`、`csv`、PDF、`docx`、`pptx`、`xlsx` 可建立本地全文索引；Office 的基础索引提取可读 XML 文本。
- 本地预览支持文本、图片、PDF。安装 LibreOffice 后，可将已接入的 Office 文档在隔离缓存目录转换为 PDF 进行高保真预览；原文件不会被修改，复杂公式、宏和嵌入对象仍可能与原应用略有差异。
- “图库浏览”会把图片和 PDF 首页缩略图缓存到应用数据目录；图片无需额外组件，PDF 缩略图要求本机 `pdftoppm`。清理缓存不会影响原文件。
- “本机工具管理”可一键安装 Tesseract OCR、FFmpeg、LibreOffice 的固定官方 `winget` 包。安装完成后重新打开应用以刷新检测；OCR 语言包、Whisper CLI 与模型仍需要你按实际需求准备。

## 索引、隐私与验收

- 资料夹变动后会进入单工作者索引队列。索引逐文件比较路径、类型、大小、修改时间与 32 MB 以下文件的 SHA-256；没有变化的文件不会再次提取正文。队列可以暂停和恢复。
- 开发环境中真实创建了 10,000 个文件进行基准：首次索引约 23 秒、无变更重扫约 0.7 秒、修改一个文件约 0.8 秒。磁盘、杀毒软件与资料类型会影响你的结果。
- PDF 正文会在本机提取并可检索；`docx`、`pptx`、`xlsx` 提供有限的 XML 文本提取和只读预览，复杂版式、公式、嵌入对象不保证显示。
- “本地数据治理”可生成 AES-256-GCM 加密备份；密钥仅保存在当前 Windows 用户的凭据库。恢复包先校验，重启应用才替换数据库，并保留恢复前副本。
- 敏感扫描报告只报告已提取文本中命中的类别、文件名和路径，不显示命中的原始内容。元数据审计可查看备注、标签与云端策略的变更记录。
- 首页的“运行环境验收”会报告本机可检查项，并将云端协作、中文路径、复杂 Office、自动更新等标为需要在最终用户设备实测的项目。

## 模型与 Agent 边界

- 可以选择自动、CPU 或 GPU 模式，并设置 llama.cpp 的线程数和上下文长度。运行时从固定版本清单下载并校验 SHA-256；GPU 是否实际可用仍取决于下载的 CUDA 构建与显卡驱动，请以环境验收和实际推理结果为准。
- 复杂任务会先在本机检索。资料的“禁止上传”策略会形成仅本机可用的受限素材绑定；云端只得到允许外发、经脱敏与最小化的摘要。最终证据报告记录步骤、构建/测试结果和受限绑定数量，不保存受限原文。
- 自动构建或测试只允许固定的 `npm`/`cargo` 检查命令，且只在用户选择的受控工作区运行。失败后可由用户触发“自动最小修复”：最多两次，只向云端发送脱敏失败摘要；每次仍只允许新建文件、固定检查，拒绝覆盖、删除、越界路径、命令注入和网络副作用。只有单独的“批准后修改已有文件”操作可覆盖已有普通文件，并且会先创建本机备份。

## 已知限制

- OCR 与音视频转写使用持久化本地任务队列。OCR 需要 Tesseract 和语言包；转写需要 Whisper CLI、Whisper 模型与 FFmpeg。结果仅进入本机全文索引，任务设有文件大小、输出长度和超时限制；未安装依赖时会明确失败。
- 图片缩略图缓存、PDF 首页缩略图（需 `pdftoppm`）和本地向量语义检索已经实现。语义检索需要用户选择本地 embedding GGUF 与本地 llama.cpp 运行时；未配置 embedding 时会明确回退到 FTS。
- 已接入资料夹的新增、修改、删除和重命名会自动触发索引刷新；网络盘、权限变化和实际超大目录仍需在真实资料库中验证。
- 云端协作、embedding 实际推理、中文路径、LibreOffice 与 `pdftoppm` 转换、Tesseract/Whisper、自动更新、GPU 推理以及真实大目录监听仍需要在你的电脑及已授权服务商环境中完成验收。
- 默认模型约 1 GB，运行时从 llama.cpp 官方 GitHub Releases 下载；下载由你在应用内主动发起。
