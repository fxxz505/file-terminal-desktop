# 资料终端桌面版

资料终端是一个 Windows 本地优先的资料管理与 AI 协作助手。你可以将已有文件夹或文件接入软件：原文件仍在原位置，软件只在本机保存索引、备注、标签、对话和任务记录，帮助你快速找到资料，并在需要时由本地 AI 与云端 AI 协作完成任务。

每次发布都会先经过 GitHub Windows 验证，再生成带签名的更新包。应用内“关于”页可检查、下载并安装新版本。

## 下载与安装

**[下载最新 Windows 版本](https://github.com/fxxz505/file-terminal-desktop/releases/latest)**

Release 页面的 `Assets` 中提供两种版本：

1. 安装版：下载名称以 `_x64-setup.exe` 结尾的文件并双击安装。
2. 便携版：下载 `资料终端便携版-win-x64.zip`，解压后双击其中的 exe。
3. 适用于 64 位 Windows 10/11，无需账号。

便携版会在 exe 同级创建 `资料终端数据` 文件夹；数据库、密钥、索引、模型、对话和设置都保存在其中。应用更新只替换程序，不会删除该数据文件夹。若需要迁移电脑或磁盘，请先关闭应用，再将 exe 和同级数据文件夹一起移动。

## 三分钟开始使用

1. 在首页将整个文件夹拖入窗口，或点击“接入文件夹”。也可以在“上传文件”区域拖入或选择多个文件。
2. 接入文件夹只保存原路径与索引，不会复制、移动、删除或改写原文件；上传文件会复制到应用数据目录的 `uploaded-files`。
3. 右键文件夹或文件，可添加备注、标签，并设置云端访问权限。已有内容会保留，由你决定是否修改。
4. 打开“本地搜索”，按名称、路径、备注、标签或已提取正文查找资料。
5. 单击文件夹可在软件内逐层浏览；单击文件可预览支持的格式，也可选择“在资源管理器中打开”。

例如，为游戏素材添加 `游戏` 标签或备注后，搜索“游戏”即可找到相关文件和文件夹。

## 主要功能

- 文件夹、文件拖拽接入，保留原始位置。
- 备注、标签与固定的云端上传权限标签。
- 本地全文、路径、标签和备注搜索；配置 embedding 模型后可用向量语义检索，未配置时会明确回退到关键词搜索。
- 图片、文本、PDF 预览；Office 文档提供基础提取及可选的 PDF 转换预览。
- 图片与 PDF 首页缩略图缓存，可在图库中浏览。
- 文件变化自动进入索引队列，支持暂停、恢复、逐文件增量更新与索引诊断。
- “后台任务”统一显示索引、媒体处理和下载任务的状态、进度、错误摘要及可用操作。
- 本地模型优先回答问题，并支持兼容 OpenAI API 的自定义云端服务商。
- 本地 AI 与云端 AI 对话自动保存，可查看、删除并解析步骤、建议和代码块。
- Agent 仅在受控工作区写入文件；修改已有文件必须明确批准，修改前会创建备份。
- 图片网页任务有本地安全回退：没有可用本地模型时，明确的图片画廊任务仍可生成待审批的 HTML 文件。
- AI 输出工作区可在软件内逐层浏览，也可直接在资源管理器中打开；新建输出默认不覆盖已有文件。
- 点击“开始任务”后会立即显示启动状态和进度反馈，完成后可查看回答、步骤、代码和输出文件。
- 本地数据库使用 SQLCipher 加密，支持 Windows 凭据、DPAPI 密钥副本、加密备份和自动恢复。
- “关于”页支持检查更新、下载进度、自动安装和重启。

## AI 协作

### 本地 AI

在“资料空间”下载本地运行时和模型，或选择电脑中已有的 GGUF 模型。可选择自动、CPU 或 GPU 模式，并设置线程数与上下文长度。

没有安装本地模型时，资料管理和关键词搜索仍可正常使用。对于明确的本地图片画廊任务，软件可生成待审批的静态 HTML；图片保留在本机，生成网页使用本地安全 `file:///` 路径。

### 云端 AI

在“设置”中的 AI 配置添加兼容 OpenAI API 的服务商：填写显示名称、基础地址和 API Key，点击“获取模型”，再选择需要使用的模型。API Key 仅保存到 Windows Credential Manager，不写入 SQLite 数据库。

复杂任务可由本地 Agent 先检索、整理和分析资料，再将允许外发的最小化内容交给云端 AI。云端返回的代码与建议会先回到本地端审查，只有经过审批才会写入受控工作区；不会直接作为系统命令执行。

### 云端访问标签

每个文件与文件夹都会显示一种云端标签：

| 标签 | 含义 |
| --- | --- |
| 云端：禁止上传 | 默认值，仅供本地索引与本地 AI 使用。 |
| 云端：允许上传 | 任务需要时可纳入最小化云端请求。 |
| 云端：每次询问 | 每次外发前都必须由你确认。 |

标签不能替代安全审查。即使资料被允许上传，软件仍会进行最小化选择、敏感规则脱敏和提示词注入检查。接入机密资料前，请确认云端服务商的条款与权限。

## 搜索、预览与索引

- 支持按文件名、路径、备注、标签和已提取正文搜索。
- `txt`、`md`、`json`、`csv`、PDF、`docx`、`pptx`、`xlsx` 可建立本地索引。
- 文本、PDF 与 Office 文件分别有独立安全限制。超限、损坏、加密或不支持的文件会明确显示“只索引元数据”或安全原因，不会静默当成空正文。
- 安装 LibreOffice 后，可将接入的 Office 文件转换为 PDF 进行隔离预览；复杂公式、宏与嵌入对象可能与原应用不同。
- 图片缩略图不需要额外组件；PDF 缩略图需要本机存在 `pdftoppm`。

## OCR、音视频与工具管理

“本地搜索”中的工具管理会区分应用下载、固定 winget 包与用户选择的外部模型。通过 Windows `winget` 安装固定官方包前必须确认：

- Tesseract OCR：识别图片文字，需要对应语言包。
- FFmpeg：音频与视频转码。
- LibreOffice：复杂 Office 转 PDF 预览。

音视频转写还需要 Whisper CLI 与本地 Whisper 模型。OCR 和转写结果只写入本机索引；依赖未安装时，软件会显示明确错误，不会静默上传文件。

取消排队媒体任务不会启动进程；取消运行中的 OCR、FFmpeg 或 Whisper 任务会终止当前进程树、清理临时目录，并且不写入识别结果或全文索引。应用意外关闭后的运行任务会安全回到队列等待重新处理。

## 下载任务与监听降级

- 工具管理中的 Whisper tiny 模型与简体中文 `chi_sim` OCR 语言包由应用内固定 HTTPS 清单下载。每项资源均有固定 SHA-256 校验、`.partial` 断点续传与原子替换；不接受用户输入的下载地址。
- 点击下载后，任务会立即出现在“后台任务”页面，显示排队、运行、失败、取消和完成进度。失败或取消可以重试，运行中的下载可以取消；应用异常退出后任务会在下次启动时自动回到队列继续。
- 下载的 Whisper tiny 会自动登记为本地转写模型。下载的中文语言包保存在应用数据目录，并通过 `--tessdata-dir` 提供给本机 Tesseract，不会修改系统安装目录。转写仍需要独立安装 Whisper CLI 与 FFmpeg。
- 资料夹监听器不可用或注册失败时，软件会提示“定时扫描降级”。每个资料夹最多每 30 秒触发一次安全增量扫描；监听器恢复后会重新注册全部已接入资料夹。

## Agent 安全边界

- 默认只允许在受控工作区中新建文件。
- 不允许删除文件、越界写入、执行任意命令、联网代码或自动发布。
- 自动构建和测试仅允许固定的 `npm` 与 `cargo` 检查命令。
- 如需修改已有普通文件，必须点击“批准后修改已有文件”并再次确认。
- 修改前会创建本机备份；失败后最多执行两次有限的诊断与最小修复循环。
- 最终报告记录步骤、构建/测试结果和受限资料数量，不保存受限资料原文。

## 数据位置与隐私

- 默认数据目录是 exe 同级的 `资料终端数据`，不是 C 盘用户目录。
- 接入文件夹只保存引用与索引；移除引用不会删除原文件。
- 数据库使用 SQLCipher 全库加密。密钥保存于当前 Windows 用户的 Credential Manager，并有同一用户可解锁的 DPAPI 副本。
- 应用支持 AES-256-GCM 加密备份。恢复前会校验备份，原数据库和恢复文件都会保留。
- 数据库无法解锁时，软件会进入安全恢复模式，保留原数据库、WAL、SHM 和恢复目录，并自动尝试恢复。只有点击“保留旧数据并新建资料库”后，才会在 exe 同级创建新的空资料库。
- 建议启用 BitLocker 或 Windows 设备加密，且不要删除 Windows 凭据和应用数据目录。

## 软件内更新

进入侧边栏的“关于”：

1. 点击“检查更新”。软件会显示连接 GitHub 的动效；网络失败时会自动重试，并提供“重试检查”。
2. 发现新版本后点击“立即更新”。软件会验证签名、显示下载进度，完成后自动安装并重启。
3. 更新只替换程序文件，不会删除 exe 同级的 `资料终端数据`。

## 已知限制

- 本地模型、embedding 模型、Whisper 模型及部分工具需要首次下载或自行准备；OCR 还需要对应语言包。
- 云端标签和脱敏可以降低外发风险，但不能保证云端服务商绝对不会保存或处理已发送内容。发送机密资料前，请审阅发送内容与服务商条款。
- 复杂 Office 排版、公式、宏和嵌入对象不保证完全还原；PDF 缩略图需要本机存在 `pdftoppm`。
- 网络盘、权限频繁变化、超大目录、GPU 推理及特殊中文路径仍需要在实际设备上验收。OCR、Whisper、LibreOffice 和 GPU 推理是否可用取决于本机依赖、驱动和模型。

## 从源码运行

仅供开发者使用：

```powershell
npm install
npm run desktop:dev
```

前端验证：

```powershell
npm test
npm run build
```

完整验证（需要 Rust 工具链）：

```powershell
npx tsc --noEmit
cargo fmt --manifest-path src-tauri/Cargo.toml -- --check
cargo test --manifest-path src-tauri/Cargo.toml
```

仓库中的 `manual-test-kit/` 是可反复使用的虚构资料夹。接入、正文索引、搜索和移除引用不删除源文件的流程已经由自动化测试覆盖；云端协作与真实 Windows/Tauri 界面操作仍应按测试包在最终设备上手动验收。
