# 资料终端桌面版

一个 Windows 本地优先的文件夹助手：文件仍保留在原位置，应用用 SQLite 在本机保存索引、备注和标签，并将小型语言模型下载到应用自身的数据目录中运行。

## 下载 Windows 版

**[下载最新 Windows 安装包](https://github.com/fxxz505/file-terminal-desktop/releases/latest)**

打开页面后，在 `Assets` 中点击 `_x64-setup.exe` 下载并安装。后续版本会通过应用内自动更新，无需重新查找安装包。

## 已完成的桌面能力

- 选择本机文件夹，递归建立目录/文件索引，不复制、移动或删除原文件。
- SQLite 本地数据库保存文件夹引用和索引。
- 文件夹引用可单独移除；该操作只删除软件内的索引、备注与标签，绝不删除原始文件夹。
- 阻止接入互为父子关系的重叠文件夹，避免同一资料被重复索引。
- 按名称、路径、备注、标签和已提取正文进行 SQLite 分页搜索，可筛选资料夹与文件类型。
- 为 `txt`、`md`、`json`、`csv`、`docx`、`pptx`、`xlsx` 建立有限的文本索引；Office 文档仅提取可读 XML 文本，不是无损版式解析。
- 文件预览、内嵌文件夹浏览、原位置失效提示及“在资源管理器中打开”。
- 应用内下载 `llama.cpp` Windows CPU 运行时。
- 应用内下载 `Qwen2.5 1.5B Instruct Q4_K_M` GGUF 模型；下载进度显示在界面内。
- 模型和运行时准备完成时，内置 `llama-cli` 将自然语言问题转换为检索词，再用 SQLite 中的真实路径、标签、备注返回结果。
- 模型尚未下载时也有安全的本地规则兜底：例如“现在想要玩游戏”会检索 `游戏`、`game`、`steam` 相关的文件夹与文件。
- 可配置兼容 OpenAI 的 HTTPS 云端提供商；API Key 仅保存到 Windows Credential Manager。
- 复杂任务可在用户启用后由本地 Agent 自动发送最小化、策略过滤、脱敏后的云端请求；云端代码只会写入新建的受控工作区，拒绝覆盖、删除、路径越界、联网代码与命令执行。

## 隐私边界

- 默认索引数据库与模型位于 `%LOCALAPPDATA%\资料终端`。
- 文件夹仅被读取来建立索引；不会上传、移动、删除或改写任何原文件。
- 默认云端策略为“禁止上传”。允许外发的内容仍经过最小化选择、敏感规则脱敏和提示词注入检查。
- SQLite 数据库目前没有应用层加密。请开启 Windows 设备加密或 BitLocker；不要将“本地优先”理解为数据库已经加密。
- 自动写入默认关闭；即使开启，也只接受结构化的低风险新文件创建，仍会拒绝覆盖、删除、安装、发布、联网和命令执行。
- 模型及运行时仅在你点击应用内下载按钮后下载。默认模型下载约 1 GB，运行时从 llama.cpp 官方 GitHub Releases 下载。

## 从源码运行

开发模式：

```powershell
npm install
npm run desktop:dev
```

## 自动更新

首次安装后，应用会从 GitHub Releases 检查新版本。发现更新时确认即可下载、安装并重启；SQLite 索引、备注、标签和已下载的模型仍留在 `%LOCALAPPDATA%\资料终端`，不会重复下载或丢失。

发布新版本时：

1. 同步更新 `package.json` 与 `src-tauri/Cargo.toml`、`src-tauri/tauri.conf.json` 中的版本号。
2. 创建并推送形如 `v0.1.1` 的 Git 标签。
3. GitHub Actions 会构建签名安装包、发布 Release，并生成 `latest.json` 供已安装客户端自动更新。

发布工作流依赖仓库 Secret `TAURI_SIGNING_PRIVATE_KEY`。私钥绝不能提交到 Git；丢失后无法继续为既有客户端签名更新。

## 当前限制

- PDF 正文、OCR、音视频转写、图片缩略图、复杂 Office 布局和向量语义检索尚未实现；这些格式目前只能靠文件名、路径和元数据检索。
- 索引是一次性或用户手动刷新，尚无文件系统监听、后台取消/恢复和大规模目录性能基准。
- 低风险自动写入只覆盖新建文件；“受限素材绑定”、逐步骤真实工具执行和构建失败后的最小公开 diff 修复仍需继续实现。
- 默认模型和运行时下载支持已验证模型的断点续传；运行时 ZIP 没有发布方校验清单，用户登记的 GGUF 只校验路径与扩展名，尚无 GPU/线程/上下文长度配置或兼容性检测。
- 云端协作、真实模型下载、中文路径、大型目录、安装包升级和 Office 提取需要在用户机器及真实授权的提供商环境中验收。
