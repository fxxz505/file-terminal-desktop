# 资料终端桌面版

资料终端是一个 Windows 本地优先的资料管理与 AI 助手。你把已有文件夹接入软件后，原文件仍保留在原位置；软件只在本机建立索引、保存备注和标签，帮助你更快找到资料并在需要时调用 AI。

## 下载与安装

**[下载最新 Windows 安装包](https://github.com/fxxz505/file-terminal-desktop/releases/latest)**

1. 打开下载页，在 `Assets` 中下载名称以 `_x64-setup.exe` 结尾的安装程序。
2. 双击安装包，按提示完成安装。
3. 从 Windows 开始菜单打开“资料终端”。

适用于 64 位 Windows 10/11。首次启动不需要账号，也不会要求上传资料。之后有新版本时，应用会在启动后检查 GitHub Release，并在你确认后下载、安装和重启。

## 三分钟开始使用

1. 在首页选择或拖入一个资料文件夹。
2. 软件递归建立本地索引，但不会复制、移动、删除或改写其中的文件。
3. 给资料夹或文件添加备注、标签；右键编辑时会保留原有内容，由你决定是否修改。
4. 在“本地搜索”输入关键词，按名称、路径、备注、标签和已提取文本查找资料。
5. 单击文件夹可在应用内逐层浏览；单击文件可预览支持的格式，或用“在资源管理器中打开”回到原位置。

例如，为游戏资料添加 `游戏` 标签或备注后，搜索“游戏”即可找到相应文件夹和文件。

## AI 助手如何工作

- 可在应用内下载小型本地模型和运行时。模型下载完成后，本地 AI 会把自然语言问题转换为检索词，并结合本机索引返回相关资料。
- 模型尚未下载时，基础关键词检索仍可使用。
- 可在设置中添加兼容 OpenAI API 的云端服务地址、API Key，并点击“获取模型”选择服务商提供的模型。API Key 仅存储在 Windows Credential Manager，不写入 SQLite 数据库。
- 本地与云端对话会保存在本机；应用可解析云端返回的步骤、代码和建议，但不会把它们直接当作命令执行。
- 复杂任务可由本地 Agent 组织云端请求：只选取允许外发的资料、对敏感内容脱敏，并将本地禁止上传的资料改为必要的抽象说明。自动写入只会在你选定的目录或应用受控工作区中新建文件，拒绝覆盖、删除、越界路径、联网代码和命令执行。

## 云端上传标签

每个资料夹和文件都显示固定的云端标签；本地模型会优先识别它：

| 标签 | 含义 |
| --- | --- |
| 云端：禁止上传 | 默认值。内容只用于本地索引和本地 AI。 |
| 云端：允许上传 | 在任务确有需要时，内容可以被纳入最小化的云端请求。 |
| 云端：每次询问 | 每次准备外发时由你确认。 |

即使标记为允许上传，应用仍会进行最小化选择、敏感规则脱敏和提示词注入检查。请在接入资料前自行确认其访问权限与云端服务商条款。

## 隐私与数据位置

- 索引、备注、标签、对话记录和已下载模型位于 `%LOCALAPPDATA%\资料终端`。
- 接入资料夹只建立引用和索引，不会改变原始资料；移除资料夹也只删除软件内数据。
- 默认云端策略为“禁止上传”。
- SQLite 数据库当前没有应用层加密。请为设备开启 Windows 设备加密或 BitLocker，且不要把“本地优先”理解为数据库已经加密。

## 支持的搜索与预览

- 支持按文件名、路径、备注、标签和已提取正文搜索，可筛选资料夹与文件类型。
- `txt`、`md`、`json`、`csv`、`docx`、`pptx`、`xlsx` 可建立有限文本索引；Office 文件仅提取可读 XML 文本，不保证保留版式。
- 本地预览支持文本、图片、PDF 以及浏览器可安全打开的部分文件类型；不支持预览时仍可在资源管理器中打开原文件。

## 索引、隐私与验收

- 资料夹变动后会进入单工作者索引队列。索引逐文件比较路径、类型、大小和修改时间；没有变化的文件不会再次提取正文。队列可以暂停和恢复。
- 开发环境中真实创建了 10,000 个文件进行基准：首次索引约 23 秒、无变更重扫约 0.7 秒、修改一个文件约 0.8 秒。磁盘、杀毒软件与资料类型会影响你的结果。
- PDF 正文会在本机提取并可检索；`docx`、`pptx`、`xlsx` 提供有限的 XML 文本提取和只读预览，复杂版式、公式、嵌入对象不保证显示。
- “本地数据治理”可生成 AES-256-GCM 加密备份；密钥仅保存在当前 Windows 用户的凭据库。恢复包先校验，重启应用才替换数据库，并保留恢复前副本。它不是 SQLite 引擎的全库加密；请同时启用 BitLocker/设备加密。
- 敏感扫描报告只报告已提取文本中命中的类别、文件名和路径，不显示命中的原始内容。元数据审计可查看备注、标签与云端策略的变更记录。
- 首页的“运行环境验收”会报告本机可检查项，并将云端协作、中文路径、复杂 Office、自动更新等标为需要在最终用户设备实测的项目。

## 模型与 Agent 边界

- 可以选择自动、CPU 或 GPU 模式，并设置 llama.cpp 的线程数和上下文长度。GPU 是否实际可用取决于下载的 llama.cpp 构建与显卡驱动；请以环境验收和实际推理结果为准。
- 复杂任务会先在本机检索。资料的“禁止上传”策略会形成仅本机可用的受限素材绑定；云端只得到允许外发、经脱敏与最小化的摘要。最终证据报告记录步骤、构建/测试结果和受限绑定数量，不保存受限原文。
- 自动构建或测试只允许固定的 `npm`/`cargo` 检查命令，且只在用户选择的受控工作区运行。写入永远是新建文件，拒绝覆盖、删除、越界路径、命令注入和网络副作用。

## 已知限制

- OCR、音视频转写需要用户安装本地 Tesseract/Whisper 与相关模型；应用会检测工具是否存在，未安装时不会伪造识别结果。当前设备只检测到 FFmpeg。
- 图片缩略图缓存和真正的向量语义检索尚未实现；当前搜索是关键词、路径、标签、备注与 FTS 正文检索。
- 已接入资料夹的新增、修改、删除和重命名会自动触发索引刷新；网络盘、权限变化和实际超大目录仍需在真实资料库中验证。
- 本地模型、云端协作、中文路径、Office 提取和自动更新需要在你的电脑及已授权服务商环境中完成验收。
- 默认模型约 1 GB，运行时从 llama.cpp 官方 GitHub Releases 下载；下载由你在应用内主动发起。

## 从源码运行

仅供开发者使用：

```powershell
npm install
npm run desktop:dev
```
