# 资料终端可重复测试资料

此文件夹用于手动验收资料终端。所有内容均为虚构演示数据，可以反复接入、移除引用、重新接入和删除后重建，不包含真实密钥、客户资料或个人隐私。

## 文件夹结构

- `website/`：一个无需安装依赖、可直接双击运行的简单网页项目。
- `assets/`：可作为资料终端接入资料的公开和受限演示素材。
- `prompts.md`：直接复制到 AI 助手中的测试提示词。
- `expected-results.md`：每项操作的预期结果和判定标准。

## 准备步骤

1. 在资料终端首页点击“接入文件夹”，选择本文件夹的 `website`。
2. 再接入 `assets`，为它添加标签 `演示`、`游戏`，备注填写“资料终端功能验收素材”。
3. 将 `assets/restricted-client-note.txt` 保持为“云端：禁止上传”。
4. 将 `assets/public-game-copy.txt` 设置为“云端：允许上传”。
5. 如需测试敏感规则，在“AI 助手”中新增规则：

   - 名称：`演示密钥`
   - 正则：`DEMO-SECRET-[A-Z0-9-]+`

6. 用浏览器直接打开 `website/index.html`，确认网页显示“资料终端演示网页”。

## 清理与重测

- 要重测索引：在资料终端中点击对应资料夹的“刷新”。
- 要重测云端权限：在右键菜单切换权限后，重新运行 `prompts.md` 中的云端协作提示词。
- 要重测已有文件修改审批：恢复 `website/notes-for-agent.md` 的原始内容，再执行对应提示词。
- 移除资料夹引用不会删除本测试资料中的任何文件。
