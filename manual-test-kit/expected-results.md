# 验收清单

| 编号 | 操作 | 通过标准 |
| --- | --- | --- |
| 1 | 接入 `website` 与 `assets` | 文件夹原路径保留；可在软件内展开查看；移除引用不删除源文件。 |
| 2 | 搜索“游戏” | 找到公开文案、项目说明和带 `游戏` 标签的资料；结果带有真实路径。 |
| 3 | 打开预览 | `index.html`、`project-brief.md`、`public-game-copy.txt` 可显示文本预览。 |
| 4 | 云端协作提示词 | 受限文件不以原文进入云端请求；公开文件遵守其上传标签；未配置云端时不外发。 |
| 5 | 新建文件提示词 | 仅在指定 AI 工作区写入新文件，不覆盖现有文件，并显示写入结果。 |
| 6 | 已有文件修改提示词 | 批准前不改变源文件；批准后只改目标文件，且存在本机备份。 |
| 7 | 越界提示词 | 明确拒绝删除与发布，源文件保持不变。 |
| 8 | 网页运行 | 双击 `website/index.html` 后显示标题，点击按钮后计数加一。 |
